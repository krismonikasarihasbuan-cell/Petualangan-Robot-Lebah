# Petualangan-Robot-Lebah
 sebuah game edukasi matematika yang terasa seperti petualangan di dunia lebah, dengan robot lebah BIMO sebagai pendamping belajar, soal faktor yang bervariasi, umpan balik yang mendidik, progres level, serta lencana bersayap yang terbang secara nyata di layar setiap kali siswa mendapatkan penghargaan.
